## Record Everything 1.6.1

**Feedback-Session: Bilder oder Pfade im Prüffenster wählen**
- Unten im Prüffenster steht jetzt der Umschalter **Bilder | Pfade**. Er gilt für alles in diesem Fenster: für das Kopieren und für „In Claude“, „In Codex“ usw.
- **Bilder:** Die Screenshots kommen als Anhänge ins Eingabefeld, danach der Prompt. Das geht auch, wenn der Agent per SSH auf einem Server arbeitet. Zum Kopieren gibt es „Bilder kopieren“ (als Dateien, wie im Finder) und „Text kopieren“.
- **Pfade:** Der Prompt nennt unter jedem Bild die Datei. Das ist für einen Agent auf diesem Mac gedacht.
- Beim Umschalten wird nur die Bildangabe im Prompt angepasst, deine Änderungen am Text bleiben erhalten. Die Wahl gilt auch für die nächsten Sessions.
