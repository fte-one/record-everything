## Record Everything 1.5.1

**Feedback-Session**
- **Bilder als Anhänge:** Beim Einfügen kommen die Screenshots jetzt als Bilder ins Eingabefeld, danach der Prompt. Das klappt auch, wenn Claude Code per SSH auf einem Server arbeitet. Dateipfade gibt es weiterhin als Option unter Einstellungen › Feedback.
- **„Was ist das hier?“:** Ruht die Maus beim Sprechen kurz auf einer Stelle, entsteht ein Bild, in dem diese Stelle mit einem gelben Kreis markiert ist.
- **Bilder in zeitlicher Reihenfolge:** Bild 3 ist immer der dritte festgehaltene Moment.
- **Kürzere Seitentitel:** ohne Anhang wie „- Google Chrome - Profil“.
- **Genauere Zuordnung** von Gesagtem zu Bildern durch kürzere Sprachstücke.
- **Sachliche Zusammenfassung:** ohne Wertung des Gesagten. Hörfehler der Spracherkennung (etwa „Sportschau“ statt „Sport-Show“) korrigiert die KI anhand der Beschriftungen im Bild.
- **Verlauf:** Im Menü gibt es neben Uploads und Aufnahmen jetzt „Feedback“. Dort lassen sich alle Sessions wieder öffnen, der Prompt kopieren oder der Ordner im Finder zeigen.
